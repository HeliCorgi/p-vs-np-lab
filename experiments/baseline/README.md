# P vs NP に向けた小実験

2026年11月4日（日本時間）

## 今回の結論

既存の4リポジトリを調べた結果を、小さく再実行できる実験にした。
当面の研究の本命は **hadwiger-nelson-lab の境界関係の抽出・圧縮・合成**。
spacetime-screening から着想した SAT 固定点実験は、固定点の存在と取得コストを区別する対照として使える。
ns-mns2-flowmap-bridge の仮定・全入力への適用範囲を明示する設計を、結論の管理に取り入れた。

新しい HN 下界や P vs NP の解決を主張するものではない。
HN の4節最小性は上流で記録済みの結果であり、今回はその記録を独立した有限全探索で再確認した。

## 再実行

Python 標準ライブラリだけを使う。追加インストール、SATソルバ、ネットワーク接続は不要。
Python 3.12.14 で全体を実行済み。

```bash
python run_all.py --out-dir reproduced
```

`results/` は今回の実行記録。`reproduced/` を別に指定すれば保存結果を上書きせずに追試できる。
`run_all.py` は上流11ファイルの SHA-256 を確認してから4つの実験を実行する。
各実験のログ、JSON、CSVと `RUN_SUMMARY.json` が出力される。

## 2. 7端子の12状態を独立に圧縮する

新規コード: `boundary_compression.py`

入力は上流の
`results/separator-left-q8-q9-relation-cnf/analysis.json`。
端子は `[q4,q5,q33,q62,q68,q78,q226]`。
色名の違いだけを同一視し、端子の順序は保つ。

| 段階 | 状態・候補数 |
|---|---:|
| 7端子を高々5色で彩色する正準分割 | 855 |
| 保存された目標の境界状態 | 12 |
| 目標の全状態から導いた共通の端子対条件 | 13個（すべて不等式） |
| その13不等式だけを満たす境界状態 | 21 |
| 除外する必要がある余分な状態 | 9 |
| 42個の等号/不等号リテラルから作る二項OR候補 | 861 |
| 目標12状態をすべて保ち、余分な状態を1つ以上除く候補 | 5 |
| 必要な追加節数の最小値 | 4 |
| この言語での最小節集合の個数 | 1 |

追加する4節は、`c(q)` を端子qの色として、次のとおり。

```text
(c(q4) != c(q226)) OR (c(q33) != c(q68))
(c(q4) != c(q226)) OR (c(q62) != c(q78))
(c(q4) != c(q226)) OR (c(q68) != c(q78))
(c(q5) == c(q33))  OR (c(q78) != c(q226))
```

0節、1節、2節、3節のすべての候補集合では9状態を除けず、4節の組合せでは1組だけが成功した。
その式を全855状態で評価し、目標12状態と一致することも確認した。
保存データの「最小4」「一意」というフラグを判定根拠には使っていない。

### 人手でも追える最小性の理由

有効な全5候補の中で、以下の余分な状態を除ける節はそれぞれ1つしかない。

| 余分な状態 | 除外できる唯一の節（上の順序） |
|---|---:|
| `0123240` | 1番目 |
| `0112320` | 2番目 |
| `0112330` | 3番目 |
| `0123444` | 4番目 |

したがって4つとも必須であり、実際に4つで十分。

### 範囲

これは**保存された12状態を入力とする、特定の表現言語内の最小性**である。
13個の共通の端子対条件を固定し、追加節を「端子対の等号/不等号を高々2個ORするもの」に限定している。
任意のBoolean式・任意のアルゴリズムに対する最小性ではない。
また、等式原子は推移性と5色制限を満たす必要があるので、普通の独立Boolean変数による2-SATと同一ではない。
元グラフのSAT葉や幾何の正しさは、この実験で再証明していない。

結果: `results/boundary_compression.json`

## 3. 部品の追加と内部の結合を分ける対照実験

新規コード: `transparent_gluing.py`

端子A,B,C,Dに、辺AB,AC,AD,BC,BDを置く。CDだけがない K4-e である。
各tipは4端子すべてに隣接する内部頂点。
5色のラベル付き割当を省略せず、4ケース合計35,000件列挙した。

`0122` は C=D、`0123` は CとDも異色という境界状態を表す。

| グラフ | 正準境界 | 固定境界0122への内部拡張数 | 固定境界0123への内部拡張数 | 正しい5彩色の総数 |
|---|---|---:|---:|---:|
| K4-eのみ | 0122,0123 | 1 | 1 | 180 |
| tip xを追加 | 0122,0123 | 2 | 1 | 240 |
| 互いに非隣接のtip x,yを追加 | 0122,0123 | 4 | 1 | 360 |
| xとyの間にも辺を追加 | 0122のみ | 2 | 0 | 120 |

境界がd色を使うとき、各場合の内部拡張数は
`1`、`5-d`、`(5-d)^2`、`(5-d)(4-d)`。
全列挙結果とこの式を照合した。

最後のケースでは、内部2頂点に異なる2色が必要になるため、境界が4色を使う状態は延長できなくなる。
外から見える制約がここで増える。

一般に、部品の内部が互いに交わらず、共有頂点が端子のみで、内部間に新しい辺がないなら、
合成した境界関係は各部品の境界関係の共通部分になる。
これらの条件を変える結合が、新しい制約を作る場所である。

**この対照は抽象的な有限グラフについてのもの。平面内の単位距離で実現できるとは主張しない。**

結果: `results/transparent-gluing/transparent_gluing_results.json`

## 4. SATを定常状態へ埋め込む実験

新規コード: `fixedpoint_sat.py`

CNF F と nビットの割当xに対し、

```text
T_F(x) = x                     if F(x) is true
         (x+1) modulo 2^n      otherwise
```

を使う。簡潔な写像の逐次評価と、2^n個の遷移をすべて列挙する検証を分けている。

| n | 割当数 | 一意解の例で0から解までの遷移数 | UNSATの例の周期 | 複数解の例の吸収点数 |
|---:|---:|---:|---:|---:|
| 4 | 16 | 15 | 16 | 8 |
| 8 | 256 | 255 | 256 | 128 |
| 12 | 4,096 | 4,095 | 4,096 | 2,048 |
| 16 | 65,536 | 65,535 | 65,536 | 32,768 |

一意解の式は全変数を1にする単位節の連言。
UNSATの式は `(x0) AND (NOT x0)`。
複数解の式は最初の2変数のXORで、他の変数は自由。
**すべて容易な式であり、表の長い反復はこの更新規則の性質だけを示す。**

SATなら全再帰クラスが充足割当の吸収点になる。
UNSATなら点としての固定点はないが、全状態を回る周期上の一様分布は定常分布になる。
これは点状態からの反復がその分布に収束するという意味ではない。

全再帰クラスを経路追跡で列挙し、入次数0の頂点を除去する別の方法でも再帰頂点集合を照合した。
周期上の一様分布が定常であることは、整数の流入数で検算している。
12ケースすべての検査が成功した。

この検証では全遷移を実際に列挙しており、指数的な時間・メモリを支払っている。
通常の計算機で固定点を安く取得できることや、物理的なCTCを実現したことを示す実験ではない。
元repoのGaussian/Fock模型をSATに置き換えたものでもない。

結果: `results/fixedpoint/fixedpoint_sat_results.json` と集計CSV。

## 境界幅が増えると何を測るべきか

端子の数kについて、5色の名前の置換だけを除いた候補数は
`sum_{j=0..5} S(k,j)`（第2種スターリング数）。
k>=1なら厳密に `(5^k + 10*3^k + 20*2^k + 45)/120`。
動的計画法の漸化式から計算し、この閉形式とも照合した。

| 端子数 | 正準候補数 |
|---:|---:|
| 6 | 202 |
| 7 | 855 |
| 8 | 3,845 |
| 10 | 86,472 |
| 12 | 2,079,475 |
| 16 | 1,275,163,905 |

これは境界上の辺などの条件を加える前の候補数であり、全表を列挙する方式の費用を表す。
短い論理式など別の表現が存在しないことまでは言わない。
今回の7端子の例は、むしろ関係を小さく表現できる具体例である。

## 次に追う研究課題

**小さく記述できる境界関係は、合成を重ねても小さいままで扱えるか。**

まず部品ごとの正確な境界関係と圧縮式を持ち、合成後の関係を検査する。
変える軸は内部の大きさだけでなく、境界幅・共有端子・内部間の結合。
測るのは全状態表、圧縮式、式を作る時間、式を合成する時間、証拠検証の費用。
小さな表現が存在しても、それを探す費用が大きい可能性も別に調べる。

一般SATへ進むには、全入力を覆う変換、単一のアルゴリズム、符号化長に対する総ビット計算量が必要。
限定された入力族で有効な手法や、特定の表現・合成方式の限界も研究成果として分けて扱う。
