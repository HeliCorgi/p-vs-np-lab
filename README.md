# p-vs-np-lab

P versus NPに関連する、再現可能な小さな定理・反例・計算実験の研究室。
**P vs NPの解決を主張していません。**

最初の研究対象は、制約系の内部変数を消去し、残った境界関係を小さく表現して合成する方法です。

## 最初の形式化

- `Formal/StarProjection.lean`: 5色・5端子の星グラフの内部中心を消去すると、境界端子の等式・不等式だけをリテラルとする補助変数なしのCNFには、10種類すべての等式を含む節が必要。
- `Formal/BoundaryComposition.lean`: 内部変数が独立に分離された二つの制約系の境界関係は、論理積で合成できる。

Lean 4.19.0、Stdのみ。通常のカーネル検査による有限判定と論理証明を使います。

```bash
lake build Formal
```

GitHub Actionsでビルドを実行します。有限実験と研究記録は続くコミットで統合します。

どちらも初等的な限定命題です。任意の表現形式・任意のアルゴリズムに対する下界でも、一般SATの解法でもありません。
