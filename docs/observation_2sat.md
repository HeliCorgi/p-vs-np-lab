# Deciding rank-two event avoidance with few dependent observations

An affine event forbids all points satisfying its equations. For each
consistent codimension-two event choose two independent normal masks `a,b`
spanning its normal plane, and express its two forbidden bits in that basis.
Introduce a Boolean observation `y_a=a·x` for each distinct selected mask.
Forbidding one prescribed pair of bits is one ordinary 2-CNF clause in the
observations. A forbidden hyperplane gives a unit clause. An inconsistent
event is discarded, while the universal event is an empty clause. Raw input
and the final lifted witness are checked in the original coordinates.

Write `K` for the number of observations, `R` for their linear rank, and
`k=K-R`. The Boolean 2-CNF is only a relaxation until **all k consistency
parities** are imposed. Gaussian elimination produces a basis of dependencies
of the selected labelled normals. Their equations say `h·y=0`. They suffice:
the image of the parameter-to-observation map has dimension `R`, lies in the
kernel of these checks, and that kernel also has dimension `R`. Consequently
a parity-consistent Boolean model lifts to an original point by solving a
linear system. If the ordinary 2-CNF is UNSAT, its restriction is UNSAT too.
The [solver](../src/pnp_lab/observation_2sat.py) returns original witnesses
and does **not** count complement points.

## An exact XP search in the deficiency k

Use the ordinary implication graph and strongly connected components to
obtain a 2-SAT model `p` if one exists. If it already obeys the parities,
return its checked lift. Otherwise translate models by `z=y XOR p`. The
translated 2-CNF contains the all-zero model. It therefore has only three
kinds of real requirements: a bit must be zero, two bits cannot both be one,
or one bit being one implies that another is one.

Regard true bits as a set. For a seed set `T`, let `M(T)` be its positive
implication closure. If the closure violates a unit or forbidden pair, no
model contains `T`, since adding true bits cannot repair that violation.
Otherwise `M(T)` is itself a model, and a model `S` contains `T` exactly
when it contains `M(T)`. This equivalence concerns the translated Boolean
formula before checking its translated parities.

**Degree lemma.** Let `f` be any multilinear polynomial over GF(2) of
degree at most `k` in the translated observation bits. If it vanishes on
all feasible `M(T)` with `|T|≤k`, it vanishes on every Boolean model of
this formula. Indeed a square-free monomial indexed by `T` evaluates to
`[T⊆S]` on the support of model `S`. Discard monomials with infeasible
closures. Combine monomials with the same feasible closure `C` to write

\[
                    f(S)=\sum_C d_C\,[C\subseteq S]
\]

on all Boolean models, using coefficients modulo two. All listed `C` are
themselves test models generated by at most `k` elements. Evaluate at each
such `C` in increasing size. If all these evaluations vanish, induction
forces every `d_C=0`: the terms for proper subsets have already vanished
and the coefficient for equality is one. This is a unit-triangular
inclusion matrix argument and does not require enumerating all 2-CNF models.

Apply the lemma to the indicator of satisfying all consistency checks:

\[
              f(z)=\prod_{h\text{ a check}}(1+h\cdot z+h\cdot p).
\]

There are `k` factors, so reducing powers by `z_i²=z_i` gives degree at most
`k`. We evaluate the parities directly, without expanding the product. If
some valid model satisfies the checks, at least one feasible small-generated
closure satisfies them. Exhausting those closures with no success proves
UNSAT. Hitting a subset budget *before* exhaustion means `UNKNOWN`.

For enumeration choose one representative from each positive-implication
SCC. An individually inconsistent closure can never be part of a model.
Skip generating subsets that contain comparable SCCs. Every nonempty
closure generated by at most `k` bits is still enumerated: take its unique
minimal generators after SCC contraction, retaining only components not
reachable from another generator. They form an antichain of size at most
`k`. This avoids keeping an exponentially large visited-closure dictionary.
There are at most `Σ_{j=0}^k binom(K,j)` seed subsets and polynomial work
per attempt in the explicit masks/formula. The solver uses polynomial
workspace, including the bitset reachability table. `subsets_tested` counts
attempts on nonempty subsets (including skipped redundancies),
`unique_closures_tested` counts feasible closures whose parity is checked,
including the empty closure for a satisfiable relaxation; `max_subsets`
does not charge input preparation or the SCC model check.

This is polynomial for **each fixed k**, but its polynomial exponent can
depend on k (XP). It is not a uniform all-input polynomial bound and does
not claim the fastest deterministic XP algorithm. The underlying problem
is known: Arvind and Guruswami, [*CNF Satisfiability in a Subspace and Related
Problems*, IPEC 2021](https://doi.org/10.4230/LIPIcs.IPEC.2021.5), Theorem
17, give a deterministic algorithm for 2-Sub-Sat at fixed codimension;
Theorem 19 establishes W[1]-hardness parameterized by codimension. Here
codimension is that of the observation-value subspace **inside the Boolean
observation space**, not the row count of an individual forbidden event.
The preceding proof specifies the lab's closure-based search rather than
claiming priority for fixed-codimension tractability.

## Exactly when a common coordinate basis suffices

We can recognize `k=0` for the *given event flats*, allowing different local
equations expressing the same flat. For each distinct normal plane `U`
there are exactly three nonzero vectors and three ways of choosing a pair.
All lines here mean their unique nonzero GF(2) representative. A common
basis must contain:

* every rank-one event's normal line;
* the shared line of every pair of distinct normal planes that intersect
  nontrivially (equivalently any nonzero line belonging to multiple planes).

For the second assertion, if `U` and `V` are generated by subsets of one
independent basis, their intersection is spanned by the intersection of
those subsets, by uniqueness of coordinates. Also, every mandatory basis
line lying in `U` must be one of its two basis generators; three distinct
mandatory lines in `U` are immediately impossible. When no plane has more
than two mandatory lines, complete its pair arbitrarily from its remaining
lines. Any such remaining line is private to just that plane and is not an
outside rank-one requirement. Hence the **total number K of distinct lines
in these mandatory completions is independent of how private slots are
filled**. The rank `R` is fixed too: every chosen pair spans the same plane.
An independent completed list (`K=R`) works and can be extended to an
ambient basis. A dependent completed list rules out every common-basis
choice, by the invariance of this size for common-basis candidates.
Affine constants affect clause signs, not the recognition test. This does
not exclude a *logically equivalent but different family of events* having
a simpler description.

When no common basis exists, the solver compares a mandatory completion
when possible, the original independent input rows, and a greedy plan
favoring reused lines. For identical normal planes one pair suffices
regardless of how many affine constants occur. The plan with smallest
`K` among those tried is used. Keeping an original-row baseline ensures
the chosen `K` never exceeds the number of distinct nonzero input masks.
It does not guarantee minimum positive deficiency.

**Why not call that choice optimal?** Given a graph `H` without isolated
vertices, take a plane `span(e_i,e_j)` for every edge and a rank-one event
with private normal `e_i+e_j` for the same edge. All edge lines must be
included. Omitting both endpoints of an edge leaves fewer than two selected
lines in its plane; conversely, retaining any vertex cover supplies at
least one endpoint per edge, enough together with its private line. Thus

\[
       K_{\min}=|E(H)|+|V(H)|-\alpha(H),
\]

where α is maximum independent-set size (a complement-graph clique;
see Karp, [*Reducibility among Combinatorial Problems*](https://doi.org/10.1007/978-1-4684-2001-2_9)).
The optimum follows by solving the local line-selection problem even if
all forbidden constants are easy (e.g. private parity 1, plane pair `00`,
so the all-ones point works). This proves NP-hardness of minimizing the
number of observations for the fixed presentation, not hardness of these
particular SAT instances or unconditional nonexistence of faster algorithms.
On a four-cycle the implemented heuristic can use seven forms while six
suffice. Recognizing an independent coordinate description and finding
the best *dependent* description are different claims.

The [tests](../tests/test_observation_2sat.py) check both SCC and closure
outcomes by direct small-point oracles, exact budget edges, compact signed
3SAT witnesses, a nonoptimal positive-deficiency example, and the complete
common-axis criterion against all ambient bases in dimension three.
