# 内部変数を消すと、境界の CNF はどれだけ大きくなるか

**線形個の小さな XOR 部品をつないだだけでも、内部変数をすべて消して境界変数だけの通常の CNF にすると、指数個の節が必要になる。**

ここで確認するのは既知の表現サイズ下界である。新しい下界の発見や、P と NP の分離を主張しない。パリティそのものは線形時間で評価でき、XOR をそのまま残す表現や幅 2 の OBDD なら小さく保てる。

実装は [parity_projection.py](../experiments/parity_projection.py)、独立な小規模の意味論検査は [test_parity_projection.py](../tests/test_parity_projection.py) にある。

## この実験で問うこと

内部変数を持つ部品の制約を `C(x,z)` とする。`x` が外から見える境界、`z` が内部である。部品を外から見た正確な関係は

\[
R(x)=\exists z\;C(x,z)
\]

となる。小さな `C` を作れたとき、その `R` も選んだ表現形式の中で小さく記述できるか。この閉性が、部品を合成する研究で確認すべき条件の一つになる。

以下では出力の表現形式を、**境界変数だけを使う、通常のリテラルの選言を節とする CNF** に固定する。補助変数、XOR 節、新しい計算ゲートは出力に許さない。

## 1. 線形個の部品を使う構成

境界を `x_1,...,x_n`、内部変数を `z_2,...,z_n` とし、次の鎖を作る。

\[
z_2=x_1\oplus x_2,\qquad
z_i=z_{i-1}\oplus x_i\quad(3\le i\le n),\qquad z_n=0.
\]

一つのゲート `c = a XOR b` は、次の 4 節で正確に表せる。

\[
(a\lor b\lor\neg c)
\land(a\lor\neg b\lor c)
\land(\neg a\lor b\lor c)
\land(\neg a\lor\neg b\lor\neg c).
\]

出力を 0 に固定する単位節を最後に足す。実装では単位伝播などの簡約を行わないので、数え方は次のとおり。

| 対象 | 個数 |
|---|---:|
| 境界変数 | `n` |
| 内部変数 | `n-1` |
| XOR ゲート | `n-1` |
| 元の CNF の節 | `4(n-1)+1` |
| 元の CNF の最大節幅 | `3` |

これはゲート数・節数では `O(n)` の構成である。変数番号を二進文字列で書く通常のファイル表現なら、記述ビット数には `log n` の因子も付く。この区別を無視して巨大な整数を一定コストで扱う主張はしない。

境界割当を一つ固定すると、各 XOR ゲートの出力は順番に一意に決まる。従って、内部変数の存在を問うことは最後のパリティが偶数であることと同値になる。

\[
\exists z\;C_n(x,z)
\quad\Longleftrightarrow\quad
x_1\oplus\cdots\oplus x_n=0.
\]

偶数パリティの境界割当には内部への拡張がちょうど一つある。奇数パリティには一つもない。

## 2. 境界だけの CNF には正確に `2^(n-1)` 節が必要

**命題。** `n >= 1` とする。偶数パリティを正確に表す、補助変数のない通常の CNF は、少なくとも `2^(n-1)` 個の節を持つ。この数の節を持つ CNF も存在する。

### 下界の証明

同じリテラルの重複は消してよい。変数とその否定を同時に含む恒真節も消してよい。残る各節は、すべての偶数パリティ割当で真でなければならない。

ここで、ある非恒真節が変数 `x_j` に言及していないと仮定する。その節に現れるすべてのリテラルを偽にする割当を選べる。まだ値を選んでいない変数を自由に補い、最後に `x_j` を選んで全体のパリティを偶数にする。`x_j` はその節に現れないため、節は偽のままである。

これは、偶数パリティの割当がその節を満たすという要件に反する。よって、**有効な非恒真節は全 `n` 変数に言及する必要がある。**

全変数に一度ずつ言及する節を偽にする割当は一つだけである。その割当は奇数パリティでなければならない。CNF 全体は `2^(n-1)` 個ある奇数パリティ割当をすべて除く必要があり、一節が除けるのはそのうち一つなので、少なくとも `2^(n-1)` 節が必要になる。

### 上界と素な節

各奇数割当 `a` に対し、その `a` だけで偽になる節を一つ作る。ビット `a_i=0` ならリテラル `x_i`、`a_i=1` なら `NOT x_i` を使う。それらをすべて連言すると偶数割当だけが残り、節数は `2^(n-1)` になる。

各節から一つのリテラルを落とすと、その変数だけを反転した偶数割当まで除いてしまう。したがって各節は素な含意節であり、より短い有効な節へ置き換えられない。各奇数割当を除く節も必要なので、どの節も丸ごとは落とせない。

これで最小節数は正確に `2^(n-1)`、最小リテラル出現数は `n * 2^(n-1)` と分かる。これは全 `n` に対する初等的な証明であり、有限個の測定から指数成長を推測したものではない。

この最小節数は既知の結果として Emdin・Kulikov・Mihajlin・Slezkin, **CNF Encodings of Parity**, MFCS 2022 の冒頭にも明記されている。同論文の主題は、補助変数を許した場合の、より精密なトレードオフである。本実験はその論文の新しい結果を再証明したとは主張しない。[一次資料](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.MFCS.2022.47)

## 3. 同じ関係は幅 2 の OBDD なら小さい

入力を順番に読み、ここまでに読んだ 1 の個数の偶奇だけを保持すればよい。必要な状態は偶数・奇数の二つだけである。実装はこの構造を実際に OBDD として作り、全境界割当に対する評価を照合する。

通常の OBDD で、補辺を使わない今回の構成の数え方は次のとおり。

- 内部ノードは `2n-1` 個。
- 終端は真・偽の 2 個。
- 各内部ノードから 2 本ずつ出るので、辺は `4n-2` 本。
- 各変数の段の幅は最大 2。

パリティが線形サイズの OBDD を持ち、通常の CNF/DNF では指数サイズになるという対照も既知である。Darwiche・Marquis, **A Knowledge Compilation Map**, JAIR 17 (2002) の Appendix A、Table 10 の説明を参照。[一次資料 PDF](https://www.cs.cmu.edu/afs/cs.cmu.edu/project/jair/pub/volume17/darwiche02a.pdf)

## 4. 有限検証の方法

既定範囲は `n=3,...,12`。全境界割当について、次を検査する。

1. XOR ゲートの 8 通りの真理値表が、片方向の含意でなく正確な同値を表すこと。
2. ゲートが強制する一意の内部割当を順に作り、元の CNF の評価と偶数パリティが一致すること。
3. 境界だけの素な CNF を明示的に列挙し、汎用のビット集合真理値表評価で同じ関係を得ること。
4. すべての素な節について、各リテラルを落としたときの偶数割当の反例を確認すること。
5. 構成した幅 2 の OBDD の評価も一致すること。

`n <= 5` では、これに加えて**すべての内部割当を独立に列挙**し、各境界割当の拡張が 0 個または 1 個であることを照合する。それより大きい `n` について内部割当を全探索したとは報告しない。一意性は各機能的ゲートからの帰納で分かる。

テストには、別の辞書ベースの真理値評価器、全 `3^5` 個の正規化された非恒真節の含意検査、ゲートの一節や最後の出力固定を落とす負例もある。

この検証器は `2^n` 個の境界割当と `2^(n-1)` 節の出力を明示的に扱う。巨大なビット集合を用いる箇所も、そのサイズの計算・記憶費用を払う。**多項式時間の圧縮アルゴリズムではない。**

## 6. この研究計画に持ち帰れる結論

「部品の境界関係を正確に求め、内部を消して小さく保存する」という方針には、**何の表現形式で小さく保つのか**という条件が必要になる。境界だけの通常 CNF に毎回戻す方針は、この簡単な族だけでも最悪の場合に指数個の節を要求される。

一方、パリティの計算自体は容易である。補助変数を残す、XOR 制約を認める、幅 2 の OBDD を使うといった方法は、この例の障害を回避する。この実験を「すべての境界圧縮が不可能」「SAT は指数時間が必要」へ拡大しない。

次に問うべきなのは、候補表現が必要な関係を小さく保持できるか、合成・射影の後もその形式を保てるか、必要な照会をどの費用で処理できるか、の組み合わせである。ここで閉じたのは、**補助変数なしの境界 CNF という一つの出力形式**に関する普遍的な小サイズ保証である。
