# Replacing branch comparisons by a proof before branching

A directed witness map compares specific residuals. On the [switchable odd-charge family](transport_obstruction.md) no two tag restrictions at the same depth admit the direct certificate, even though the entire instance has a short parity refutation. This note gives a generic one-pass rule that can find such a proof, an independent verifier over the original 3-CNF, and an NP-complete class on which the rule learns nothing.

## Linear consequences common to both cases

Think of one XOR equation as an augmented vector (a,b) encoding a·x=b over GF(2). XORing equations adds these vectors. First extract original equations: for each support of at most three bits, collect its clauses. If they exclude all sign patterns of parity 1-b, the CNF implies the equation of parity b. A group can imply both right sides; a false empty clause yields 0=1.

Next choose an input bit t. On side 0 use input clauses containing positive t and erase that literal. On side 1 do the same for clauses containing negative t. Extract affine equations from these short clauses, separately on each side. Let U,V be their augmented row spans. **Every vector in U∩V is an unconditional consequence**: when t=0 it has one XOR derivation and when t=1 another, with the same variables and right side. The code does not assert the converse and does not learn all consequences of a conditional contradiction.

To compute a spanning set for the intersection, insert the left rows followed by the right rows into one Gaussian basis and keep a bit mask of original row indices for each elimination. Each dependency involving both sides gives the same row as their separate XORs. Conversely, any common vector has representations on both sides and their difference is such a dependency; pivot dependencies span the kernel (left-only and right-only dependencies give zero common vector). Collect the unconditional rows from all pivots once; reject if their total span contains (0,1). A branch variable need not be a known selector. The search uses no auxiliary promise about the input and runs in polynomial time on the explicit bit encoding: two appearances of the same assignment in different branches never create an enumerated cross-product. The number of local sign patterns checked per leaf is at most eight. Coefficient masks and provenance use polynomially many bits. UNKNOWN means that no contradiction was found by the pass.

[Independent replay](../src/pnp_lab/split_parity.py) checks every local step by evaluating the specified **original clause indices** on the few named bits with the guard fixed, checks that the two conditional XORs coincide, and finally checks that all the unconditional rows in the certificate XOR to 0=1. It does not rerun the discovery algorithm or trust the pivot order. [Optional private-pivot resolution](private_resolution.md) can first append short clauses justified by the input to expose rows hidden by splitting a clause. Its certificate verifies the resolvents before verifying the nested parity proof. This is a root UNSAT prepass: if it returns UNKNOWN, the ordinary driver can still decide either way.

On the 128-switch input, the unpadded generic root pass produced a checked 1,691-term contradiction on 2,204 variables and 5,178 clauses. The satisfiable even-charge control was not refuted. The 2^128 tag restrictions were **not enumerated**. The older affine labels are already able to merge restrictions on the unpadded family; these measurements show a different way of proving UNSAT, not a lower bound for that driver. See [small proof and size records](../results/split_parity.json), and the [padded controls](transport_padding.md).

## A blind, NP-complete class, even with the private-resolution prepass

Suppose each clause is on exactly three distinct variables, and at most one clause has any particular unsigned support. Then the original extraction never sees four bad patterns on the same triple. After splitting any bit, each affected pair support has at most one clause (it came from the unique triple consisting of that pair and the split bit), fewer than the two needed for a parity equation. Thus **even after scanning every pivot, zero rows are extracted**. A formula in this class can be SAT or UNSAT.

Here is a direct polynomial reduction from any width-at-most-three CNF. The [code](../src/pnp_lab/simple_support.py) includes an explicit fixed gadget on six variables with eleven unique supports. A truth table of just 64 entries shows that it is UNSAT. Deleting the clause (¬4 ∨ ¬5 ∨ ¬6) leaves exactly the two models with bitmasks 62,63 in one-based variable order. In either model, 4,5,6 are true. Use the ten remaining clauses, and use their negations ¬4, ¬5, ¬6 as false padding literals.

For each occurrence in a normalized non-tautological source clause introduce a distinct copy of its original variable, carrying the original sign. Pad length two with ¬6 and length one with ¬4,¬6. An empty clause adds the omitted gadget clause once. Enforce equality of all copies of each original variable by a directed cycle of implications, padding each binary implication with ¬4. If there are exactly two copies, use ¬5 for the second direction so the two clauses have different supports. Single copies need no cycle. Finally add (¬6 ∨ u ∨ v) on two fresh variables: every previous model extends with u=true.

All output triples are distinct: occurrence words of different clauses are disjoint, original binary clauses and equality clauses use different padding, and the cycle edges have distinct supports except for the explicitly handled reverse pair. Original solutions extend to the gadget and equal copies, and each output solution decodes to one consistent value per used source variable. This is decision preservation; multiplicities need not agree. The construction has linear size in occurrences, with the usual logarithmic cost for variable indices. Therefore SAT on these outputs is NP-complete by the standard NP-completeness of 3SAT (and is in NP by checking a word).

Moreover, no output variable occurs exactly once per polarity. A copy on a cycle occurs in both incident implications as well as its source clause; a singleton copy or either new padding variable occurs only once in total. Gadget bits 1–5 already violate the requirement within the ten clauses; bit 6 has an additional negative occurrence in the final clause. Consequently [the private-pivot pass](private_resolution.md) cannot append even one clause on these inputs. **The two root rules together are silent on an NP-complete image**, regardless of the truth of P versus NP. This is not a lower bound on the subsequent transport, label or unrestricted SAT algorithms. In particular the private-resolution escape on the padded Tseitin family and this reduction are different statements.
